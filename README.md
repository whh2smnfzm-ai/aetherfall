# Aetherfall: The Last Spire — Web MVP

An original dark-fantasy mercenary auto-battler prototype.

## Run
Open `index.html` in a modern browser. No build tools or server are required.

## Included in v0.1
- Mercenary roster and 3-person party selection
- Automatic turn-based battles
- Endless floor progression with scaling enemies
- Crown and Aether rewards
- Permanent company-wide attack and health upgrades
- Browser-local save data (`localStorage`)
- Responsive layout for mobile and desktop

## Notes
This is an early playable prototype. It uses original placeholder emoji artwork and a compact single-file implementation. Online accounts, cloud saves, multiplayer, App Store packaging, advanced skills, equipment drops, and production-grade balancing are not included yet.
